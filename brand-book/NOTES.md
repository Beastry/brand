# Beastry 母品牌视觉规范

> 方向：柔和野兽气质（暖色点缀）+ 动物家族主调  
> 正式标志：可爱 JPG（圆形 Mark / 水平 Lockup）

## 标志

| 用途 | 文件 | 说明 |
|------|------|------|
| 圆形 Mark | `cute-mark-rcb.jpg` | 粉兔 / 蓝猫（珊瑚内耳）/ 黄熊 + 打开的书 |
| 水平 Lockup | `cute-lockup-rcb.jpg` | Mark + 小写 `beastry`（a 字怀珊瑚色心） |

净空 ≥ Mark 直径 1/8。Favicon / App icon 建议 Mark ≥ 32px；顶栏 Mark ≥ 40px；Lockup 字标高 ≥ 24px。

## 色彩

| 角色 | 色值 | 用法 |
|------|------|------|
| Cream | `#FFF6EE` | 页面底、浅表 |
| Charcoal | `#2A2421` | 正文、标题、结构 |
| Coral | `#FF6B4A` | 主 CTA、心形、小点缀（少用） |
| Peach | `#FFD6C7` | 面 / 卡片 |
| Sky | `#D6E9F6` | 面 / 卡片 |
| Honey | `#FFE8B8` | 面 / 卡片 |
| Mint | `#D6ECE7` | 面 / 卡片 |
| Lavender | `#E7E2F6` | 面 / 卡片 |

规则：一屏一个主珊瑚操作；粉彩只做面；正文用 Charcoal；不做珊瑚铺底 header。

## 字体

- 字标为图形资产（圆角粗体小写 + 心形 a）；正文勿用系统字仿打官方 lockup
- 标题：粗圆角无衬线；正文：干净无衬线；代码：等宽

## 寓言三兽

母品牌仅此三兽，用于标志本身：

1. **粉兔** — 好奇与轻盈  
2. **蓝猫** — 专注与陪伴（珊瑚内耳）  
3. **黄熊** — 稳妥与守护（与打开的书同框）

## 应用

- **App icon**：奶油底圆角方标，无外圈，放大插画居中，四周留白约 9–12%
- **Favicon / 头像**：圆形 Mark
- **Open Graph 1200×630**：奶油底 + 居中 lockup + 短标语 + beastry.app
- **README 横幅**：左 lockup，右中英短标语

## 语气

温暖 · 可玩 · 清楚 · 开源友好。短句、主动语态；承认限制，给出下一步。避免神话式口号。
