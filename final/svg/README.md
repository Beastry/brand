## 使用建议

- 印刷 / 大尺寸：优先 `mark.svg`、`lockup.svg`
- Web / 体积敏感：可用 `.min.svg`，或继续用 JPG 栅格
- Favicon / 小尺寸：优先 `mark`（圆章），避免 lockup 在极小尺寸糊字
- 不要手改路径去「修可爱度」——若栅格更新，应重新一比一描摹并替换本目录
