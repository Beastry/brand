# 02 · 颜色

色值以 [`../tokens/tokens.json`](../tokens/tokens.json) / [`../tokens/tokens.css`](../tokens/tokens.css) 为准（2026-11-03）。

## 核心（A Soft Beast · 20%）

| Token | 色值 | 用途 |
|-------|------|------|
| `color.surface.cream` | `#FFF6EE` | 页面底、卡片浅底 |
| `color.text.charcoal` | `#2A2421` | 正文、标题、字标描边感 |
| `color.accent.coral` | `#FF6B4A` | **主 CTA**、字标心形、书脊 / 小点缀 |

规则：一屏珊瑚只服务 **1 个主操作** + 少量小点缀；不要大面积铺珊瑚。

## 系统粉彩（E Animal Family · 80%）

| Token | 色值 | 用途 |
|-------|------|------|
| `peach` | `#FFD6C7` | 产品卡 / 面 |
| `sky` | `#D6E9F6` | 产品卡 / 面 |
| `honey` | `#FFE8B8` | 产品卡 / 面 |
| `mint` | `#D6ECE7` | 产品卡 / 面 |
| `lavender` | `#E7E2F6` | 产品卡 / 面 |

粉彩只做**面与背景**，不做正文色。每个产品尽量固定一色，不在同一产品上堆多种粉彩。

## Logo 内可见色（描述，非另开 token）

- 粉兔填充：浅粉（贴近 peach 家族）
- 蓝猫填充：浅蓝（贴近 sky）；内耳可用更醒目的暖珊瑚点缀对齐定稿
- 黄熊填充：浅蜜黄（贴近 honey）
- 书页：近白；书脊：珊瑚暖红

## 不要

- ❌ 霓虹、高饱和科技蓝紫当主色（偏离 A20/E80）
- ❌ 粉彩当小字颜色（对比不足）
- ❌ 用珊瑚当整页 header 底
