# 04 · 寓言三兽

设计板：[`../brand-book/07-fable-beasts.png`](../brand-book/07-fable-beasts.png)。

母品牌仅此三兽，用于标志本身：

1. **粉兔** — 好奇与轻盈（长耳、浅粉）
2. **蓝猫** — 专注与陪伴（尖耳、浅蓝；珊瑚内耳）
3. **黄熊** — 稳妥与守护（圆耳、浅黄；与打开的书同框）

气质：kawaii / 手绘炭线、圆润、共读打开的书。

## 规则

- 三兽顺序固定：粉兔 → 蓝猫 → 黄熊
- 用于母品牌 mark / lockup / 品牌说明插画
- 本规范不定义各产品吉祥物；产品视觉由各产品自行维护
