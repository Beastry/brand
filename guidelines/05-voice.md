# 05 · 语气 Voice

设计板：[`../brand-book/08-voice.png`](../brand-book/08-voice.png)。

## 气质关键词

温暖 · 可玩 · 清楚 · 开源友好

## 可以这样说

- 短句、主动语态；中英都可，按受众切换
- 承认限制；给出下一步
- 强调共读 / 共创，而不是神话品牌

## 尽量避免

- 纹章腔、贵族腔、神秘学黑话
- 纯营销空话（「颠覆」「赋能」堆砌）
- 嘲讽用户或其他开源项目

## 品牌名书写

- 对外正式： **Beastry**
- Logo 图形：全小写 `beastry`（含心形 a）
- 仓库 / npm 等标识：遵循各平台惯例，优先保持可搜索的 `beastry` / `Beastry`
