# 06 · 应用 Applications

## 官网 beastry.app

- Header：圆形 `mark`（栅格或 SVG）
- Hero / 关于品牌：可用 `logo-lockup`
- 底色 Cream；主按钮 Coral；产品卡片用粉彩面
- Favicon：可用 `mark.jpg`；有需要时可再导出方形 SVG favicon

## GitHub / 文档

- 组织与仓库 README 顶部可用 lockup 或 mark
- 产品 README 以**产品吉祥物**为主视觉，母品牌 mark 放次要位置（页脚或「Part of Beastry」）

## 社交头像 / 开放图谱

- 头像：裁切圆形 mark，保留圆框与三兽可读性
- OG 图：cream 底 + lockup 居中，左右留白

## 幻灯 / 印刷

- 优先矢量 `final/svg/*.svg`；大篇幅插画勿把 logo 拉成海报主插画（需要插画另绘）

## 检查清单

- [ ] 用的是 v3 可爱定稿 / 一比一 SVG，不是几何重绘稿
- [ ] 三兽顺序仍是粉兔 → 蓝猫 → 黄熊
- [ ] 未把产品兽塞进母品牌圆章
- [ ] 珊瑚未铺满背景
- [ ] 文字为 Charcoal，粉彩只做面
